Lumen-themed ChatKit embed

This page demonstrates the standalone-HTML path for embedding OpenAI ChatKit with Lumen's theme. The Lumen tokens are inlined above as :root { --color-spring-500: …; … } — the same set lumenChatKitCssVariables() emits.

Initialize ChatKit with the resolved theme:

import { lumenChatKitThemeResolved } from "../../design-system/02-components/_chatkit-theme/lumen-chatkit-theme";

Then mount ChatKit normally; it reads the now-defined CSS variables. Zero per-component overrides.

ChatKit embed mounts here.
Add <script src="https://cdn.openai.com/chatkit/latest.js"></script> and call OpenAIChatKit.mount(...) with theme = lumenChatKitThemeResolved.

See design-system/02-components/_chatkit-theme/README.md for the full integration recipe.
