# notes/

Working notes drafted while building Lumen. Not part of the design system contract — these are scratch / drafts / "thinking out loud" by humans or AI agents.

Promote a note to `research/` when it earns a citation in an ADR or a `_meta/decisions/*.md`. Promote to `design-system/00-foundations/` when it becomes canonical guidance.

Files here are gitignored if they end in `.draft.md`. Everything else is checked in so the team can audit the trail.
