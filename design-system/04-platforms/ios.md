# iOS — Lumen v0.13 platform guide

> SwiftUI on iOS 17+ with Swift 5.10+. Token graph distributed as a Swift Package; Satoshi Variable bundled into the app target. Apple's first-class accessibility APIs (`accessibilityReduceTransparency`, `accessibilityReduceMotion`, Dynamic Type) carry Lumen's contract end-to-end.

## 1. What this platform is

iOS is the **operator-in-the-field** surface. The Warp products that live here:

- **Driver app** — truckers on the road. Lumen single-pane visual contract for trip cards, pickup / delivery checklists, BOL signing, voice dispatch.
- **Operator companion** — dispatchers and brokers on the move. Lane lookup, rate-check, shipment timeline, ETA push notifications.
- **Cross-dock supervisor checklist** — pallet scan-in, dock-bay assignment, exception flagging. Glass overlay on a dock-camera live preview.
- **Carrier iOS sales aide** — quote-builder offline-tolerant, deep-link to lane-arc on the marketing site.

Distribution: Swift Package at `github.com/NeelMyno/warp-lumen-ios` (Phase 6 publishes). Consumer pulls the package, imports `LumenTokens`, bundles Satoshi as a resource, gets full Lumen contract.

## 2. Token mapping table

Lumen semantic tokens translate to SwiftUI types as follows. Generated by the Phase 0 Style Dictionary pipeline into [`dist/swift/Lumen+Colors.swift`](../../dist/swift/Lumen+Colors.swift) and [`dist/ios/LumenTokens.swift`](../../dist/ios/LumenTokens.swift) — never duplicate values; reference the generated constant.

### Surface

| Lumen token | SwiftUI / iOS API | Notes |
|---|---|---|
| `surface.canvas` | `LumenColors.surfaceCanvas` (resolves to `#0D0D0D`) | Page background. Use as `Color(LumenColors.surfaceCanvas).ignoresSafeArea()` on root containers. |
| `surface.raised` | `LumenColors.surfaceRaised` | Card / sheet / panel background. |
| `surface.sunken` | `LumenColors.surfaceSunken` | Inset surfaces — table track behind a tab indicator, search-field rest state. |
| `surface.popover` | `.background(.ultraThinMaterial)` | Hover popovers, tooltip-equivalents. Defers to SwiftUI's native material so the system handles vibrancy + Reduce Transparency for free. |
| `surface.glass` | `.background(.regularMaterial)` + `.colorScheme(.dark)` | Floating shells — nav bars, command palette, hero device frames. Always paired with the dark colorScheme so material samples the obsidian canvas correctly. |
| `surface.glass-strong` | `.background(.thickMaterial)` | Sheets, full-screen modals, action sheets. |
| `surface.tint-accent` | `LumenColors.surfaceTintAccent` | Spring-green-tinted surfaces (selected nav item, AI-affordance card). |
| `surface.inverse` | `LumenColors.surfaceInverse` | Paper-on-dark moments — receipts, BOL preview in dark UI. |

|---|---|---|
| `motion.duration.instant` (0ms) | `.animation(nil, value: state)` | Hard cut. Use when reduce-motion fires. |
| `motion.duration.micro` (80ms) | `.animation(.easeOut(duration: 0.08), value: state)` | Press, focus, ripple cap. |
| `motion.duration.fast` (140ms) | `.animation(.easeOut(duration: 0.14), value: state)` | Hover, focus appearance. |
| `motion.duration.base` (200ms) | `.animation(.easeOut(duration: 0.2), value: state)` | Default state transitions. |

| `motion.rate-ticker` (40000ms linear loop) | `.animation(.linear(duration: 40).repeatForever(autoreverses: false), value: offset)` | Marquee rate ticker. Pausable on long-press. |

## 3. Identity budget

**Lumen claim: ~75% of pixel surface.** What claims the rest:

- **Apple system chrome** (~15%): status bar, home indicator, keyboard, picker wheels, share sheet, alert dialog, system action sheet, Apple Maps embed.
- **System gestures + haptics** (~3%): swipe-back, pull-down to dismiss, haptic feedback on toggle.
- **Dynamic Type override** (~5%): users who scale text past XXL get spacing the app must adapt to. Lumen honors Dynamic Type up to AccessibilityLarge; past that, the contract is best-effort.
- **Wallet / Maps / Files surface embeds** (~2%): when the app deep-links into another app, that app paints.

The 75% includes everything Lumen-paintable: navigation bar (custom-styled), tab bar (custom-styled — `UITabBarAppearance` and SwiftUI's `.toolbarBackground`), every screen body, every sheet, every popover, every full-screen modal.

## 4. Glass / blur translation

### Surface mapping

| Lumen role | SwiftUI material | When to use |
|---|---|---|
| `surface.popover` | `.ultraThinMaterial` | Tooltip, hover-card-equivalent (long-press menus). Thinnest blur. |
| `surface.glass` | `.regularMaterial` | Nav bar overlays, command palette content, hero device frame. |
| `surface.glass-strong` | `.thickMaterial` | Sheets, full-screen modals, dock-camera scrim. |
| Floating action button | `.regularMaterial` + `.colorScheme(.dark)` | The FAB-equivalent on the driver app's quote screen. |

### Reduce Transparency handling

iOS exposes the user's preference via:

```swift
@Environment(\.accessibilityReduceTransparency) var reduceTransparency
```

Pattern:

```swift
.background(
    reduceTransparency
        ? AnyShapeStyle(Color(LumenColors.surfaceRaised).opacity(0.92))
        : AnyShapeStyle(.regularMaterial)
)
```

When `reduceTransparency == true`, swap material backgrounds for solid `Color(LumenColors.surfaceRaised)` at ≥85% opacity. Lumen tokens already define `surface.glass.fallback` for this — use it.

### What you can't do on iOS

- **`Modifier.blur()` does NOT exist as a "blur the backdrop" primitive in SwiftUI before iOS 17.** Use `.background(.regularMaterial)` — that's what Apple's HIG considers idiomatic.
- **Custom blur radius** is not exposed. The materials are fixed (ultra-thin, thin, regular, thick, ultra-thick). If a designer asks for "12px blur," map to the nearest material (`.thinMaterial` = ~10px equivalent).
- **Glass on background of `List` rows fails legibility.** Don't apply material to row content. Use solid `surface.raised` and let the row stack on canvas.

## 5. Motion translation

### Duration ladder

The Lumen 80/140/200/320/480ms ladder maps directly to SwiftUI's `.easeOut(duration:)`. Use `.timingCurve(0.2, 0, 0, 1, duration:)` when you specifically want the Lumen decelerate cubic-bezier rather than Apple's default ease-out.

### Easing tokens

| Lumen easing | SwiftUI |
|---|---|
| `easing.linear` | `.linear` |
| `easing.decelerate` (default, `0.2, 0, 0, 1`) | `.timingCurve(0.2, 0, 0, 1, …)` |
| `easing.accelerate` (`0.4, 0, 1, 1`) | `.timingCurve(0.4, 0, 1, 1, …)` |
| `easing.emphasized` (`0.2, 0, 0, 1`) | Same as decelerate — SwiftUI doesn't differentiate. |
| `easing.bounce` (`0.34, 1.56, 0.64, 1.0`) | `.spring(response: 0.4, dampingFraction: 0.5)` (parameterized to overshoot ~14%). Reserved for celebration moments only. |
| `easing.material-standard` (`0.4, 0, 0.2, 1`) | `.timingCurve(0.4, 0, 0.2, 1, …)` |

### Springs

Lumen ships two springs; SwiftUI parameterizes via response (period) and damping fraction. The Phase 0 token values:

| Lumen spring | SwiftUI |
|---|---|
| `motion.spring.default` (k=280, d=28, m=1) | `.spring(response: 0.38, dampingFraction: 0.84)` |
| `motion.spring.gentle` (k=200, d=32, m=1) | `.spring(response: 0.44, dampingFraction: 1.0)` |

### Reduce Motion handling

```swift
@Environment(\.accessibilityReduceMotion) var reduceMotion

.animation(
    reduceMotion ? .linear(duration: 0) : .timingCurve(0.2, 0, 0, 1, duration: 0.2),
    value: state
)
```

When `reduceMotion == true`, **all** spring + ease animations collapse to instant. The LiveDot pulse and RateTicker marquee are gated separately — they remove the `.repeatForever(…)` modifier under reduce-motion.

### Signature loops

```swift
// LiveDot pulse — Lumen's one always-on gesture.
struct LiveDot: View {
    @Environment(\.accessibilityReduceMotion) var reduceMotion
    @State private var pulse = false

    var body: some View {
        Circle()
            .fill(Color(LumenColors.actionPrimaryBgRest))
            .frame(width: 8, height: 8)
            .scaleEffect(pulse ? 1.3 : 1.0)
            .opacity(pulse ? 0.4 : 1.0)
            .animation(
                reduceMotion
                    ? nil
                    : .easeInOut(duration: 1.5).repeatForever(autoreverses: true),
                value: pulse
            )
            .onAppear { if !reduceMotion { pulse = true } }
    }
}
```

## 6. Typography translation

### Loading Satoshi

1. Drop `Satoshi-Variable.otf` and `Satoshi-VariableItalic.otf` into the app target's bundle resources.
2. Register in `Info.plist`:

```xml
<key>UIAppFonts</key>
<array>
    <string>Satoshi-Variable.otf</string>
    <string>Satoshi-VariableItalic.otf</string>
</array>
```

3. Reference via `Font.custom("Satoshi-Variable", size: 14)` or extend `Font`:

```swift
extension Font {
    static func lumenBody(_ size: CGFloat = 14) -> Font {
        Font.custom("Satoshi-Variable", size: size)
    }
}
```

### OpenType feature coverage

iOS Core Text fully renders Satoshi's OpenType features. Lumen's `.lumen-mono` translates to:

```swift
Text(value)
    .font(.custom("Satoshi-Variable", size: 14))
    .fontFeatureSettings("tnum", "lnum", "zero")  // tabular, lining, slashed-zero
    .kerning(0)  // calt off — disable contextual alternates for numerics
```

`.lumen-label` (mono-uppercase tracked):

```swift
Text("LANE CODE".uppercased())
    .font(.custom("Satoshi-Variable", size: 12).weight(.semibold))
    .tracking(1.92)  // 0.16em × 12px
    .fontFeatureSettings("tnum")
```

### Dynamic Type

Satoshi honors Dynamic Type when wrapped through SwiftUI's `.font(.body)` semantics. Lumen's body-md (14px) maps to `Font.body` for scaling.

Best practice: use Lumen's named font ramp directly (`Font.lumenBody`, `Font.lumenLabel`, etc.) for fixed sizes on dense data surfaces; use SwiftUI's `Font.body` / `.callout` / `.subheadline` for body content that should scale with the user's accessibility setting.

### What carries / what doesn't

| Capability | Status on iOS |
|---|---|
| Variable font weight axis (300–900) | ✓ Full support — `.fontWeight(.thin)` through `.fontWeight(.black)`. |
| Italic VF axis | ✓ — `.italic()` modifier picks `Satoshi-VariableItalic`. |
| `tnum` (tabular numerals) | ✓ via `.fontFeatureSettings("tnum")`. |
| `lnum` (lining numerals) | ✓ Same mechanism. |
| `zero` (slashed zero) | ✓ Same. |
| `ss01–ss04` (stylistic sets) | ✓ — `.fontFeatureSettings("ss01")`. |
| Optical sizing | ✗ Satoshi doesn't ship optical-size axis. |
| Auto-italic on accent word | Manual — wrap the single italic word in a separate `Text` with `.italic()` and concatenate with `+`. |

## 7. Specific don'ts (iOS Lumen Law)

- **Don't apply `.regularMaterial` to `List` rows or `LazyVStack` rows.** Material under dense data fails legibility — mirrors the web rule against glass on data tables. Use solid `Color(LumenColors.surfaceRaised)`.
- **Don't override the system status bar color** unless you're in a full-bleed hero. iOS users expect the status bar to read the surface beneath; respect that.
- **Don't bypass `accessibilityReduceTransparency` / `accessibilityReduceMotion`.** Every material background needs the fallback branch; every animation needs the reduce-motion check. CI verifies via XCUITest.
- **Don't ship custom blur radius via `Image.gaussianBlur`.** Apple's materials are tuned to match system chrome. Custom blur drifts.
- **Don't replace `UINavigationBar` with a fully custom view** unless you're in a hero context. Use `.toolbarBackground(.regularMaterial)` and let the system handle scroll-aware vibrancy.
- **Don't ship Lumen icons as SF Symbols** unless an SF Symbol exists and matches the Lumen 1.5px stroke contract. Lucide-ish icons should ship as bundled SVG assets (loaded via SwiftUI's `Image("lumen-truck")`).
- **Don't put Spring Green on the navigation bar tint** — even as accent. Reserve accent for actionable affordances (button labels, live-dot, accent text). The nav bar is chrome, not action.

## 8. Reference snippets

### Primary button

```swift
import SwiftUI

struct LumenPrimaryButton: View {
    let label: String
    let action: () -> Void
    @Environment(\.accessibilityReduceMotion) var reduceMotion

    var body: some View {
        Button(action: action) {
            Text(label)
                .font(.custom("Satoshi-Variable", size: 14).weight(.semibold))
                .foregroundStyle(Color(LumenColors.actionPrimaryFg))
                .frame(maxWidth: .infinity, minHeight: 44)  // iOS touch-target floor
                .background(Color(LumenColors.actionPrimaryBgRest))
                .clipShape(RoundedRectangle(cornerRadius: 6))
                .shadow(color: Color(LumenColors.actionPrimaryBgRest).opacity(0.25), radius: 16, y: 4)
        }
        .buttonStyle(LumenPressableButtonStyle())
        .animation(reduceMotion ? nil : .timingCurve(0.2, 0, 0, 1, duration: 0.14), value: 0)
    }
}

struct LumenPressableButtonStyle: ButtonStyle {
    func makeBody(configuration: Configuration) -> some View {
        configuration.label
            .brightness(configuration.isPressed ? -0.08 : 0)
            .animation(.easeOut(duration: 0.08), value: configuration.isPressed)
    }
}
```

### Stat (the Lumen signature)

```swift
struct LumenStat: View {
    let value: String      // "98.2%"
    let label: String      // "ON-TIME DELIVERY"
    let unit: String?      // optional unit like "/wk"

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            HStack(alignment: .firstTextBaseline, spacing: 4) {
                Text(value)
                    .font(.custom("Satoshi-Variable", size: 49).weight(.bold))
                    .foregroundStyle(Color(LumenColors.textPrimary))
                    .fontFeatureSettings("tnum", "lnum", "zero")  // .lumen-mono contract
                if let unit {
                    Text(unit)
                        .font(.custom("Satoshi-Variable", size: 18).weight(.medium))
                        .foregroundStyle(Color(LumenColors.textTertiary))
                }
            }
            Text(label)
                .font(.custom("Satoshi-Variable", size: 11).weight(.semibold))
                .tracking(1.76)
                .foregroundStyle(Color(LumenColors.textTertiary))
        }
    }
}
```

### Glass popover

```swift
struct LumenGlassPopover<Content: View>: View {
    @Binding var isPresented: Bool
    let content: () -> Content
    @Environment(\.accessibilityReduceTransparency) var reduceTransparency

    var body: some View {
        if isPresented {
            content()
                .padding(16)
                .background(
                    reduceTransparency
                        ? AnyShapeStyle(Color(LumenColors.surfaceRaised).opacity(0.92))
                        : AnyShapeStyle(.regularMaterial)
                )
                .clipShape(RoundedRectangle(cornerRadius: 12))
                .overlay(
                    RoundedRectangle(cornerRadius: 12)
                        .stroke(Color(LumenColors.borderDefault), lineWidth: 1)
                )
                .shadow(color: .black.opacity(0.18), radius: 20, y: 8)
                .colorScheme(.dark)  // Force material to sample obsidian canvas
        }
    }
}
```
