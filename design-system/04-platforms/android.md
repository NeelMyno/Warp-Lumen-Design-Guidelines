# Android — Lumen v0.13 platform guide

> Jetpack Compose on Android API 26+ (Android 8.0). Compose 1.7+ recommended for the accessibility manager carry-overs. `dev.chrisbanes:haze:1.x` provides the **backdrop blur** primitive Android's stock `Modifier.blur` cannot offer.

## 1. What this platform is

Android is the **field-operator surface** for markets where iOS share is < 30% — every market outside the US Driver-iPhone reality. The Warp products that live here:

- **Driver app — Android variant** — feature-parity with iOS, distributed via the Play Store and Warp's APK fleet (carrier-fleet devices preloaded).
- **Warehouse forklift tablet** — ruggedized Android tablets in cross-docks, oversized touch targets, glove-on operation. Lumen contract still applies but tunes `size.control.touch` floor to 56px.
- **Carrier dispatcher Android** — partner-fleet dispatchers without iPhones.
- **Driver android-tv reference dock** — long-haul rest-stop dashboards.

Distribution: Kotlin module published at `dev.warp:lumen-compose` (Phase 6 publishes to Maven Central via Sonatype). Consumer adds the dependency, gets `LumenTheme`, `LumenColors`, `LumenTypography`, glass surface composables.

## 3. Identity budget

**Lumen claim: ~70% of pixel surface.** What claims the rest:

- **Android system chrome** (~20%): status bar, navigation bar (or gesture pill), keyboard, picker dialogs, share intent, system alert, in-app review prompts.
- **OEM skins** (~5%): Samsung One UI keyboards, Pixel theme overlays. Best-effort respect — Lumen wins inside its own canvas.
- **Foreground service notifications** (~3%): the persistent "Tracking active" notification on driver app. Notification chrome is OS-painted.
- **Play Store consent flows** (~2%): in-app updates UI, billing flows. OS-painted.

The 70% includes top app bar (custom-styled), bottom nav (custom-styled), every screen body, every modal sheet, every BottomSheet, every Drawer.

## 4. Glass / blur translation

### The critical caveat (read this twice)

Android's stock `Modifier.blur()` is **API 31+ (Android 12+) ONLY** and blurs **the element, not the backdrop**. This makes it useless for Lumen-style frosted-glass surfaces where the content beneath needs to bleed through.

**Always use Haze:**

```kotlin
import dev.chrisbanes.haze.HazeState
import dev.chrisbanes.haze.hazeSource
import dev.chrisbanes.haze.hazeEffect
import dev.chrisbanes.haze.HazeStyle

val hazeState = remember { HazeState() }

// On the backdrop (the content you want to blur):
Box(modifier = Modifier.hazeSource(hazeState)) {
    PageContent()
}

// On the foreground (the glass surface):
Box(
    modifier = Modifier
        .hazeEffect(hazeState) {
            backgroundColor = LumenColors.surfaceCanvas
            blurRadius = 20.dp
            noiseFactor = 0f  // Lumen ships its own grain via overlay
            tints = listOf(HazeTint(LumenColors.surfaceGlassTint))
        }
) {
    PopoverContent()
}
```

### Haze + reduced-transparency fallback

Compose's accessibility manager exposes the user's preference via:

```kotlin
val accessibilityManager = LocalAccessibilityManager.current
val isReduceMotionEnabled = accessibilityManager?.isReduceMotionEnabled ?: false
```

**Important Compose quirk:** Android lumps reduce-motion and reduce-transparency into a **single signal** on most devices (read from `Settings.Global.TRANSITION_ANIMATION_SCALE`). When that's 0, treat both as "reduce on" — swap Haze surfaces for solid `LumenColors.surfaceRaised` at 92% alpha.

Pattern:

```kotlin
val accessibilityManager = LocalAccessibilityManager.current
val reduceMotion = accessibilityManager?.isReduceMotionEnabled ?: false

if (reduceMotion) {
    Box(modifier = Modifier.background(LumenColors.surfaceRaised.copy(alpha = 0.92f))) {
        PopoverContent()
    }
} else {
    Box(modifier = Modifier.hazeEffect(hazeState) { blurRadius = 20.dp }) {
        PopoverContent()
    }
}
```

### API 30 and below

Glass falls back to a solid `LumenColors.surfaceRaised` at 0.92 alpha. Document this on every Compose component MD. Haze itself supports API 21+ via a CPU-side render path, but on cheaper devices the perf is unacceptable for floating shells. Default policy: feature-detect at `Build.VERSION.SDK_INT < 31` → solid fallback.

### Reduce-motion handling

```kotlin
val reduceMotion = LocalAccessibilityManager.current?.isReduceMotionEnabled ?: false
val spec: AnimationSpec<Float> = if (reduceMotion) snap() else LumenSpring.default
```

When reduce-motion fires, every spring → `snap()` (instant). LiveDot pulse and RateTicker marquee drop their `infiniteRepeatable` wrapping under reduce-motion.

### Signature loops

```kotlin
@Composable
fun LiveDot() {
    val accessibilityManager = LocalAccessibilityManager.current
    val reduceMotion = accessibilityManager?.isReduceMotionEnabled ?: false

    if (reduceMotion) {
        Box(
            modifier = Modifier
                .size(8.dp)
                .clip(CircleShape)
                .background(LumenColors.actionPrimaryBgRest)
        )
    } else {
        val infinite = rememberInfiniteTransition(label = "live-dot")
        val scale by infinite.animateFloat(
            initialValue = 1f,
            targetValue = 1.3f,
            animationSpec = infiniteRepeatable(
                animation = tween(1500, easing = EaseInOut),
                repeatMode = RepeatMode.Reverse,
            ),
            label = "scale",
        )
        Box(
            modifier = Modifier
                .size(8.dp)
                .scale(scale)
                .clip(CircleShape)
                .background(LumenColors.actionPrimaryBgRest)
        )
    }
}
```

## 6. Typography translation

### Loading Satoshi

Drop the OTF files into `app/src/main/res/font/`:

- `satoshi_variable.otf`
- `satoshi_variable_italic.otf`

Register via XML resource `app/src/main/res/font/satoshi_variable.xml`:

```xml
<font-family xmlns:app="http://schemas.android.com/apk/res-auto">
    <font app:fontStyle="normal" app:fontWeight="400" app:font="@font/satoshi_variable" />
    <font app:fontStyle="italic" app:fontWeight="400" app:font="@font/satoshi_variable_italic" />
</font-family>
```

Define typography in Compose:

```kotlin
val SatoshiFontFamily = FontFamily(
    Font(R.font.satoshi_variable, FontWeight.Normal),
    Font(R.font.satoshi_variable, FontWeight.Medium, fontVariationSettings = "'wght' 500"),
    Font(R.font.satoshi_variable, FontWeight.Bold, fontVariationSettings = "'wght' 700"),
    Font(R.font.satoshi_variable_italic, FontWeight.Normal, FontStyle.Italic),
)

val LumenTypography = Typography(
    bodyMedium = TextStyle(
        fontFamily = SatoshiFontFamily,
        fontSize = 14.sp,
        lineHeight = 22.sp,
        fontFeatureSettings = "tnum, lnum, zero",  // .lumen-mono contract
    ),
)
```

### OpenType feature coverage

Compose 1.7+ supports `fontFeatureSettings` on `TextStyle`. Lumen's `.lumen-mono`:

```kotlin
val LumenMono = TextStyle(
    fontFamily = SatoshiFontFamily,
    fontFeatureSettings = "tnum, lnum, zero",  // tabular + lining + slashed-zero
    fontVariationSettings = "'wght' 500",
)
```

`.lumen-label` (mono-uppercase tracked):

```kotlin
val LumenLabel = TextStyle(
    fontFamily = SatoshiFontFamily,
    fontSize = 12.sp,
    fontWeight = FontWeight.SemiBold,
    letterSpacing = 1.92.sp,  // 0.16em × 12sp
    fontFeatureSettings = "tnum",
)

// Usage:
Text(value.uppercase(), style = LumenLabel)
```

### Variable font axes

Compose 1.7+ supports variable font axes through `fontVariationSettings`. Sets `wght` continuously from 300 to 900. Italic VF axis isn't yet exposed in Compose's typography API — use the separate Italic file as fallback.

### Dynamic text scale (Android equivalent of Dynamic Type)

Compose respects user font scale via `LocalDensity.current.fontScale`. Lumen body sizes scale with it. For dense data surfaces (data table, stat grid) where scaling breaks layout, lock font size via `TextStyle(fontSize = 14.sp, lineHeight = 22.sp).copy(platformStyle = PlatformTextStyle(includeFontPadding = false))` and clamp to the user's setting cap.

## 7. Specific don'ts (Android Lumen Law)

- **Don't use `Modifier.blur()`** as a backdrop primitive. It blurs the element. Use Haze.
- **Don't ship glass surfaces below API 31** without testing on a real low-end device. Haze's CPU path is slow on rendering-bottlenecked devices.
- **Don't override the system bar contrast detection** via `WindowCompat.setDecorFitsSystemWindows`. The Lumen dark canvas pairs with the OS dark status bar tint automatically.
- **Don't use Material 3 default colors.** Compose Material 3 ships with its own `MaterialTheme.colorScheme`. Override at the `MaterialTheme(colorScheme = LumenColorScheme.toMaterial3())` root so Material 3 components also pick up Lumen tokens.
- **Don't ignore the gesture-pill region.** When painting hero canvas full-bleed, account for `WindowInsets.systemBars.asPaddingValues()` so the gesture bar doesn't obscure interactive elements.
- **Don't apply Haze to `LazyColumn` items.** Same legibility cliff as iOS — material under dense data fails. Use solid surfaces for list rows.
- **Don't run the LiveDot pulse animation under low-battery (BatteryManager.BATTERY_STATUS_DISCHARGING + level < 0.15).** Voluntarily pause to save battery on driver devices. This isn't an OS signal — it's a Lumen-on-driver-app courtesy.

## 8. Reference snippets

### Primary button

```kotlin
@Composable
fun LumenPrimaryButton(
    label: String,
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
) {
    val interactionSource = remember { MutableInteractionSource() }
    val isPressed by interactionSource.collectIsPressedAsState()
    val accessibilityManager = LocalAccessibilityManager.current
    val reduceMotion = accessibilityManager?.isReduceMotionEnabled ?: false

    val brightness by animateFloatAsState(
        targetValue = if (isPressed) 0.92f else 1f,
        animationSpec = if (reduceMotion) snap() else tween(80, easing = LumenEasing.decelerate),
        label = "press",
    )

    Box(
        modifier = modifier
            .heightIn(min = 48.dp)  // Material 3 touch target; iOS uses 44, Android uses 48
            .clip(RoundedCornerShape(LumenDimens.radiusMd))
            .background(LumenColors.actionPrimaryBgRest.copy(alpha = brightness))
            .clickable(
                interactionSource = interactionSource,
                indication = null,  // We paint our own press feedback
                onClick = onClick,
            )
            .padding(horizontal = 16.dp),
        contentAlignment = Alignment.Center,
    ) {
        Text(
            text = label,
            style = LumenTypography.labelLarge.copy(
                fontFamily = SatoshiFontFamily,
                fontWeight = FontWeight.SemiBold,
                color = LumenColors.actionPrimaryFg,
            ),
        )
    }
}
```

### Glass popover (Haze)

```kotlin
@Composable
fun LumenGlassPopover(
    hazeState: HazeState,
    content: @Composable BoxScope.() -> Unit,
) {
    val accessibilityManager = LocalAccessibilityManager.current
    val reduceMotion = accessibilityManager?.isReduceMotionEnabled ?: false

    val surfaceModifier = if (reduceMotion) {
        Modifier.background(LumenColors.surfaceRaised.copy(alpha = 0.92f))
    } else {
        Modifier.hazeEffect(hazeState) {
            backgroundColor = LumenColors.surfaceCanvas
            blurRadius = 20.dp
            tints = listOf(HazeTint(LumenColors.surfaceGlassTint))
        }
    }

    Box(
        modifier = surfaceModifier
            .clip(RoundedCornerShape(LumenDimens.radiusLg))
            .border(1.dp, LumenColors.borderDefault, RoundedCornerShape(LumenDimens.radiusLg))
            .padding(16.dp),
    ) {
        content()
    }
}
```
